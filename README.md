# Technical Resolution Specialist Apprenticeship

A 90-day, hands-on production support apprenticeship building evidence of operational readiness for roles such as **Application Support Analyst**, **Production Support Analyst**, **Technical Support Engineer**, and ultimately **Technical Resolution Specialist** at enterprise organizations.

This repository is my evidence locker: every lab, incident report, runbook, script, and project lives here, version-controlled and timestamped.

## Program Structure

| Phase | Days | Focus |
|:---|:---|:---|
| **Phase 1 — Operations Foundation** | 1–30 | Linux, Bash, logs, services, incident management, networking basics, RCA writing |
| **Phase 2 — Application & Database Support** | 31–60 | Java/Spring Boot support, REST API troubleshooting, PostgreSQL, CI/CD basics, monitoring |
| **Phase 3 — Enterprise Simulation & Interview Readiness** | 61–90 | Monitoring dashboard, alerting, escalation workflows, mock interviews, job targeting |
